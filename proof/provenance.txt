# Honest caveats
The attested artifact is the in-tree escript. beamchain has no relocatable
deploy pin — the NIF is loaded from _build/default/lib/rocksdb/priv/.
/proc/<pid>/exe is the BEAM VM (beam.smp), not the escript. Path identity
(argv[0]) is the closure; byte-identity of a live process vs this file is
UNPROVEN if the on-disk escript was rebuilt after launch.
A different OTP, zlib, or build path is expected to produce different
bytes. Behavioural re-runs (R1 vectors, in-repo T1 eunit) are the
stronger check. See scripts/reproducible-escript.sh.
This script refreshes provenance + MANIFEST only. Frozen evidence in
r1/ r2/ r4/ r5/ is not regenerated from outside this repository.
